External Resources

Hand-picked, mostly-free places to go deeper — vendor docs, training platforms, standards, and tools. Green badges are free training.

Networking fundamentals

Start here if networking is new. Plain-English courses and practice.

Professor Messer Free↗
professormesser.com
Free, complete video courses for CompTIA Network+ and Security+ — the fastest way to build a foundation.
Practical Networking ↗
practicalnetworking.net
Exceptionally clear write-ups on how routing, switching, NAT and subnetting actually work.
Cisco Networking Academy — Skills for All Free↗
skillsforall.com
Free self-paced Cisco courses (Networking Basics, CCNA-aligned) with hands-on labs.
ipcalc — subnet calculator ↗
jodies.de/ipcalc
Paste an IP/CIDR and instantly see network, broadcast, host range and mask. A daily-driver tool.

Meraki Documentation ↗

The full knowledge base for cloud-managed Meraki switches, APs and security appliances.

Standards, tools & certifications

The primary sources and the tools engineers keep open.

RFC Editor ↗
rfc-editor.org
The actual internet standards — e.g. RFC 2132 (DHCP options, incl. Option 43), RFC 1918 (private IPs).
IANA Protocol Registries ↗
iana.org
Authoritative registries for DHCP options, port numbers, and other assigned parameters.
Wireshark Free↗
wireshark.org
The packet analyzer. Capture a DHCP exchange and watch Option 43 arrive in real time.
PacketLife Cheat Sheets ↗
packetlife.net
One-page printable references for OSPF, BGP, EIGRP, STP, IPsec, subnetting and more.
