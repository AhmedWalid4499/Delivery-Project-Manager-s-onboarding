🚀 Launchpad

Your tools, one click away

Every system a DPM uses on a delivery — from the GOLD order to the HOTO paperwork — in one place. Set your own links once and this browser remembers them.

Launch a tool

Grouped the same way as the handbook's Tools & Systems section. A tool marked No link yet has no team default — select ⚙ Set my links and paste the address you use.

Your links stay in this browser

Links you set are saved only in this browser.

  • 🔒They're kept in this browser's local storage on this device (under the name dpmkb_tool_links). They are never sent to a server, never shared with teammates and never added to the site's repository.
  • 💻Another browser or computer, a private window, or clearing your browsing data means setting them again. If the browser blocks storage, the launcher tells you and keeps your links only until you leave the page.
  • 🚫Paste the plain address of the tool only — never a link with a password, token or session ID in it. Links with a username or password in them are refused.
  • ↩️To remove them: ⚙ Set my links, then Reset on one tool or Clear all my links.

For maintainers

How the launcher is put together, for whoever looks after the Knowledge Base.

Set a team default link

Team defaults are the links everyone sees until they set their own. They live in the TOOLS list at the top of launcher.js — one entry per tool, and its url field is the team default:

// launcher.js — the TOOLS list at the top of the file
{
  id: "gold", name: "GOLD", emoji: "📦", group: "Delivery",
  purpose: "Order management — where the customer order lives. …",
  url: ""   // team default — leave "" for internal tools
}
  1. Open launcher.js and find the tool in TOOLS.
  2. Put the full address in url, starting with https://. Anything that isn't http or https is ignored.
  3. Commit the change. A viewer's own link still overrides the team default.
⚠️

This repository is public. Anything written in launcher.js can be read by anyone on the internet, so internal addresses (GOLD, ServiceNow, MACHX, FLIP, DNAC, SALTO, SharePoint, PRIME) are deliberately left empty. Only Power BI and Power Automate have team defaults, because their public sign-in pages are safe to publish. Fill in internal defaults only once the site is hosted privately — until then, each DPM sets their own links.

Add or change a tool

Add an entry to TOOLS with a unique lowercase id, a name, a one-line purpose, an emoji and a group — either "Delivery" or "Reporting, time & automation". An optional short name is used on the compact chips. Keep the purposes in step with the Tools & Systems section on the home page.

Put the launcher on another page

Add a placeholder where it should appear, and load launcher.js before shared.js:

<div data-kb-launcher="compact"></div>   <!-- one row of chips -->
<div data-kb-launcher="full"></div>      <!-- grouped cards + Set my links -->

<script src="launcher.js"></script>
<script src="shared.js"></script>

In compact mode, a tool without a link shows a muted Add link chip that opens tools.html#edit, which starts this page in edit mode.
